# BioQuest 11 🧬🎮

A free, browser-based Grade 11 Biology revision game covering biodiversity, classification, prokaryotes and eukaryotes, viruses, fungi, antibiotics, vaccines, and related topics.

## Play

Once GitHub Pages is enabled, play at **https://faryxlabs.github.io/BioQuest-11/**.

## Features

- Shuffle-style exam practice with scoring and XP
- Memory cards for definitions
- Review missed questions and try them again
- Works on phones and computers; once loaded it can run offline

## Hosting

This is a single-page HTML game. To publish it using GitHub Pages: open **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, and click **Save**.

The game is for practice and is not an official exam or answer key.
